# 주문·드론 데모 편집

목적: 원본 화면 녹화에서 주문, 관리자, 드론 모니터링 흐름을 이해하는 70초 영상.
우선순위: 실제 서비스 화면, 장면별 설명 자막, 테스트 결제/시뮬레이터 범위.
원본은 보존하고 무의미한 대기·중복 이동 구간을 잘라낸다. 실제 주문 완료나 비행을 새로 실행하거나 녹화에 없는 동작을 주장하지 않는다.
출력: 1920×1080 H.264 MP4, UTF-8 SRT/VTT, 컷 목록 JSON, 장면별 검수 이미지.
자막: Noto Sans KR, 36px, 높은 대비, 최대 두 줄, 주요 버튼을 가리지 않는 별도 하단 영역.
색상: 기존 앱의 surface #faf7f2, ink #292524, brand #c21f3a, muted #78716c.
Layout: 영상 프레임 - 녹화 화면과 읽기 자막을 분리 -> frame + stack (https://github.com/changeroa/StyleGallery/blob/main/patterns/stacking/stack.md); scroll owner: 없음(1920×1080 고정 출력); anti-patterns: 영상 위 주요 버튼을 덮는 자막, 긴 한글 문장 잘림, 장식 카드 중첩.
Playwright는 원본 영상 탐색, 실제 폰트 적용, 타이틀·자막 합성 화면 렌더링, 프레임 검수와 최종 재생 검증에 사용한다. 최종 H.264 인코딩은 기존 시뮬레이터 이미지에 포함된 FFmpeg를 별도 격리 컨테이너로 실행한다. 서비스 컨테이너는 재시작하지 않는다.
원본은 영상 트랙만 있는 무음 녹화이다. 관리자 원본은 30.36초에서 중단되어 확인된 앞부분(5.2–9.2, 20.9–24.9초)만 사용한다.
