# 간식·사진 자동 가져오기

`import_snacks.py`는 농심몰 스낵 카테고리의 실제 상품명·표시 가격·상품 이미지를 읽고 기존 재고 API 및 영속 사진 저장소에 반영합니다. 실행 후 관리자 상품 선택 목록과 학생 목록이 동일 DB를 조회합니다.

```sh
ADMIN_USERNAME=... ADMIN_PASSWORD=... python3 infra/catalog/import_snacks.py
```

서버의 기존 관리자 환경변수를 사용하며 자격 증명을 커밋하거나 출력하지 마세요. 기본 백엔드는 로컬 `http://127.0.0.1:18081`, 기본 한도는 공식 카테고리 첫24개입니다. 결과와 원본 URL은 `runtime/qa/snack-import.json`에 남습니다.

- 기존 SKU/상품명 매칭 상품의 판매가·재고·활성 상태와 등록 사진은 덮어쓰지 않습니다. 새우깡90g은 기존 새우깡 상품과 연결합니다.
- 빠진 상품만 고정된 `NSHOP-상품번호` SKU로 생성합니다. 실제 재고를 알 수 없으므로 새 상품의 재고는0개이며 학생에게 품절로 표시합니다.
- 공식 사진은 JPG·PNG·WebP/1MB 이하만 받아 서버 로컬 사진 저장소에 저장합니다. 학생 기기의 사진 캐시는 기존 공유 로직을 따릅니다.
- 기존 포테이토칩·젤리·우유 상품에 사진이 없는 경우 프로젝트에 이미 있던 해당 상품 이미지를 연결합니다.
- 여러 번 실행해도 같은 SKU를 중복 생성하거나 사용자가 바꾼 사진을 덮어쓰지 않습니다. 자동 주기 실행은 등록하지 않았습니다.
